# Jinliang Zheng — Personal Website

Personal academic website for Jinliang Zheng, featuring research interests, selected publications, honors, education, and an up-to-date CV.

The site is intentionally dependency-free and served as a static GitHub Pages site from the `simple` branch.

## Local preview

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
